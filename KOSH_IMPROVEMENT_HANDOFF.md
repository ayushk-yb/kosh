## 2. In-Depth Technical Specifications & Solutions

### 2.1 SMS Deduplication & OTP Filter Engine
#### The Problem
- When clicking "Scan", `Telephony.Sms.Inbox` cursor reads all messages. Every message matching the regex inserts a new row with autogenerated ID into Room `transactions` table.
- When an online purchase occurs, two SMS are received:
  1. *OTP SMS*: "OTP is 492019 for transaction of Rs. 1,552.00 at AMAZON PAY... Do not share."
  2. *Debit SMS*: "Your A/C ending 4012 is debited for Rs 1552.00 on 26-Oct at AMAZON..."

#### The Solution
1. **Rejection Filter**: Reject any message containing:
   - `otp`, `one time password`, `verification code`, `security code`, `code is`, `valid for`, `do not share`, `secret code`.
   - Also reject bank promotional offers (`pre-approved`, `loan`, `apply now`, `cashback points`, `discount voucher`).
2. **Deterministic Deduplication**:
   - Add a `smsRefId` or `hash` column to `TransactionEntity` (e.g. SHA-256 of `date_rounded_to_minute + amount + instrument + first10charsTitle`).
   - In `TransactionDao`, add `@Insert(onConflict = OnConflictStrategy.IGNORE)`.
   - Before inserting during batch scan, query existing transaction hashes or filter in memory against database records.
   - Add a "Reset / Clear Duplicates" helper in ViewModel to clean existing bloated databases.

### 2.2 Full-Life-Cycle Notifications (Debits + Credits + Bill Reminders)
#### 1. Instant Transaction Notification on Spend
Update [`SmsBroadcastReceiver.kt`](app/src/main/java/com/kosh/app/receiver/SmsBroadcastReceiver.kt):
- Listen for `SMS_RECEIVED`.
- Run through OTP/promo rejection filter.
- Support both **Debits** (spends, UPI, card charges) and **Credits** (refunds, transfers).
- Insert directly into Room DB via Repository (avoiding duplicate).
- Show Heads-Up Notification with actions:
  * **Title**: `₹1,552 spent at Amazon`
  * **Subtitle**: `Paid via ICICI Bank • Tap to split or categorize`
  * **Action 1**: `[ Split Bill ]` -> Launches `MainActivity` with `EXTRA_EDIT_TRANSACTION_ID` + `ACTION_SPLIT`.
  * **Action 2**: `[ Categorize ]` -> Launches `MainActivity` with `EXTRA_EDIT_TRANSACTION_ID` + `ACTION_CATEGORIZE`.

#### 2. Household Bill Reminders (WorkManager)
- Create `BillReminderWorker : CoroutineWorker`.
- Schedule a daily periodic work request (`PeriodicWorkRequestBuilder<BillReminderWorker>(24, TimeUnit.HOURS)`).
- Checks `householdObligations` where `isPaid == false`.
- If today is within 2 days of `dueDayOfMonth` or on the due date:
  * Trigger notification: `Rent is due tomorrow (₹30,000)` with action `[ Pay & Split ]`.

### 2.8 Launcher Adaptive Icon Fix (Eliminating the White Squircle)
- Create `res/values/colors.xml`:
  `<color name="ic_launcher_background">#0F141C</color>`
- Create `res/mipmap-anydpi-v26/ic_launcher.xml` and `ic_launcher_round.xml`:
  ```xml
  <?xml version="1.0" encoding="utf-8"?>
  <adaptive-icon xmlns:android="http://schemas.android.com/apk/res/android">
      <background android:drawable="@color/ic_launcher_background"/>
      <foreground android:drawable="@mipmap/ic_launcher_foreground"/>
  </adaptive-icon>
  ```
- Generate `ic_launcher_foreground.png` (432x432 with the circular wheel in the center 288x288 safe zone) across mipmap densities.
- On OEM launchers (Vivo, Samsung, Pixel), this guarantees the icon seamlessly uses the dark background rather than forcing a white box around the circle.

## 3. Database Cleanup Script / Migration

Because the user currently has > ₹1 Crore of duplicated transactions in their local database from multiple scans:
- In `KoshViewModel.kt`, provide a one-tap `cleanupDuplicateTransactions()` routine:
  - Finds all transactions with identical `timestamp`, `grossAmount`, and `title`.
  - Keeps only the earliest record and deletes all duplicates.
  - Recalculates net spend and updates the dashboard immediately.
